# Etapas reaproveitáveis

O fluxo completo é sequencial, pula etapas aprovadas e permite executar uma isoladamente. Registre concluído/pendente em oferta.md e vincule as saídas.

| Etapa | Trabalho | Saída |
|---|---|---|
| Enquadrar | Perfil + projeto. Refine serviço existente; em ideia nova, use competências/recursos relatados. | O que desenvolver, sem inventar especialidade. |
| Pesquisar | Pesquisa/concorrentes para perguntas de decisão. | pesquisa/ com fontes, datas e limites. |
| Escolher solução | Compare poucas opções se ainda aberto; não gere opções por obrigação. | Escolha e justificativa. |
| Formato e condições | Serviço: escopo, capacidade, atendimento, região. Digital: formato, suporte, produção e acesso. Preço do dono ou hipótese explícita. | Condições aprovadas/a validar. |
| Estruturar oferta | Entregas, problema, valor esperado sem garantia, evidência, objeções e limites. | oferta.md revisada. |
| Escrever página | Seções necessárias, tom aprovado, CTA com destino real ou demo. | texto-pagina.md revisado. |
| Definir visual | direcao-visual reutiliza marca/contexto. | visual/direcao-visual.md + previa.html. |
| Criar página | pagina com revisão local. | site/index.html + pagina-revisao.md. |
| Divulgar, se pedido | Rascunhos de criativo/post/roteiro de vídeo, com provas disponíveis. Use conteudo. Não envie/publique. | conteudo/ com status. |
| Projetar, se pedido | Cenários com hipóteses de capacidade, preço, conversão e custos; mostre cálculo e sensibilidade. Não é previsão garantida. | projecao.md com premissas. |

Expresso termina no próximo resultado útil: projeto e oferta curtos. Visual e HTML local só conforme o ritmo. Não executa as últimas etapas automaticamente nem esconde pesquisa longa. Completo pode continuar em outras sessões usando os registros.
