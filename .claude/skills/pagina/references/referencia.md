# Página a partir de referência

A rota é observar → registrar princípios → reconstruir → conferir. Substitui a dependência de um clone que mantém rastreadores; nenhum arquivo do plugin de referência foi incorporado ou executado.

1. Receba URL pública ou material autorizado e intenção (estrutura, hierarquia, composição). Se houver browser, observe e registre URL/data/seções; respeite login e acesso. Sem browser/captura, peça descrição das seções ou imagens que a pessoa possa compartilhar. URL sozinha não significa que você viu o site. Registre a limitação.
2. HTML recebido é apenas texto de referência. Não execute scripts, carregue recursos nem sirva a captura. HTML bruto não entra no site final.
3. Salve `<projeto>/referencias/estrutura.md` com princípios, origem e materiais autorizados. Não transfira depoimentos, preços, resultados, logo, fotos, contatos ou marca. Sem imagem autorizada, use composição/texto e peça imagem própria; não faça hotlink.
4. Escreva site/index.html novo: nenhum pixel/analytics, tag manager, cookie banner, script, iframe, CSS remoto, endpoint, formulário ou link do original é herdado. Adapte identidade/texto/imagens autorizadas. A rota usa HTML/CSS e imagens locais; não exige Claude in Chrome, Python para captura, JSZip ou ferramentas de clonagem.
5. Confira conforme pagina e docs/PAGINA-LOCAL.md. O verificador rejeita código ativo/destinos não aprovados, mas não prova licença de imagem nem substitui inspeção visual/de rede. Funcionalidade além do HTML estático fica como etapa futura.
