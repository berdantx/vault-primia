# Relatório

Leia INSTRUCOES.md, perfil.json e arquivos indicados do projeto. Confirme destinatário/objetivo se faltar. Use modelos/relatorio.md; reaproveite visual aprovado para HTML local quando pedido, sem instalar ferramentas.

Separe trabalho feito, resultado medido, decisão e hipótese. Cada métrica precisa de período, unidade e fonte; sem medição, escreva “não medido”. Identifique limites e próximos passos com responsáveis/prazos informados. Não transforme tarefa concluída em resultado financeiro presumido.

Salve `<projeto>/relatorios/AAAA-MM-DD-assunto.md` (ou HTML pedido), preserve versões e vincule em projeto.md. Mostre para revisão. Não envie automaticamente.
