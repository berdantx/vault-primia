# Rotinas do kit

No Claude Code, use os nomes abaixo ou peça em português. No Codex, use seletor de skills/$nome. Os arquivos canônicos ficam em .claude/skills e as entradas Codex em .agents/skills. Não há cópias concorrentes em .claude/commands.

| Rotina | Resultado |
|---|---|
| /audiencia | Analisa comentários e respostas fornecidas separando contagens observadas de hipóteses sobre o público. |
| /concorrentes | Compara concorrentes e alternativas relevantes com evidências e lacunas explícitas. |
| /conteudo | Cria ideias e roteiros no tom do perfil com oferta e materiais autorizados do projeto. |
| /diario | Abre ou retoma o dia com projetos, pendências e inbox; funciona também em uma base vazia. |
| /direcao-visual | Define e salva a identidade visual do negócio com uma prévia aprovada para páginas e documentos. |
| /humanizar | Revisa texto para o tom do perfil sem inventar fatos, histórias ou disfarçar limitações. |
| /inbox | Organiza materiais da inbox por pedido explícito com proposta de destinos e preservação dos originais. |
| /oferta | Desenvolve oferta de serviço ou infoproduto em modo expresso, completo ou por etapa. |
| /pagina | Cria HTML local para a oferta aprovada ou a partir de referência, sem rastreadores ou publicação. |
| /pesquisa | Pesquisa mercado com evidências, fontes, datas e limitações para decisões do projeto. |
| /projeto | Cria o primeiro projeto com oferta, público, problema e objetivo usando o perfil aprovado. |
| /proposta | Prepara proposta comercial revisável com escopo, exclusões e condições fornecidas na oferta. |
| /relatorio | Organiza relatório do projeto com evidências, resultados observados, lacunas e próximos passos. |
| /reuniao | Transforma transcrição fornecida em decisões, responsáveis, pendências e registro ligado ao projeto. |
| /setup | Configura ou revisa o perfil do negócio preservando dados existentes e preparando o primeiro projeto. |
| /tldr | Fecha a sessão com decisões, pendências e próximo passo no diário e no projeto pertinente. |

A primeira tarefa é projeto, não diário. frontend-design/theme-factory apoiam direcao-visual e já estão incluídas com recursos/licenças. Canvas-design é opcional, não incluída. publicar permanece como orientação compatível para um pedido explícito fora da oficina; não é chamada por pagina nem instala hospedagem.

Mapa padrão: projetos, clientes, inbox, diario, reunioes, pesquisa, conteudo, arquivo, pessoal. O perfil pode manter alunos/lancamentos ou nomes escolhidos. Rotinas consultam esse mapa; dados não são movidos ao renomear uma preferência.
